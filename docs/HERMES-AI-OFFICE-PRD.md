# Hermes AI Office — Product Definition

AI Office is an execution console for delegated software development. Its product surface is deliberately small.

## User value

The operator can answer at a glance:

- What is running now?
- When did each task start and how long has it run?
- What finished, failed, paused, or was cancelled?
- How many tokens, calls, dollars, and execution-hours have been consumed?
- Which project, logical model, physical model, and provider/channel consumed them?
- Is OpenHands/LiteLLM healthy and how close is the runtime to readiness promotion?

No organization chart or staffing administration is part of the product.
